# Object-Oriented Client-Server Application

This project is an object-oriented application developed as part of my software development learning path. It focuses on applying object-oriented programming principles, layered architecture, secure development practices, and high-quality code design.

## Overview

The application demonstrates the use of OOP concepts, SOLID principles, design patterns, unit testing, and client-server communication. It includes a graphical user interface, data persistence, and socket-based communication between application components.

## Key Features

- Object-oriented application design
- Layered software architecture
- Graphical user interface
- File and database persistence
- Socket-based client-server communication
- Unit testing
- Use of design patterns
- Secure development principles

## Technologies

- Java
- OOP
- Sockets
- Database persistence
- Unit testing

## Status

This project was developed as an academic project and is included in my portfolio to demonstrate my object-oriented programming and software architecture skills.
